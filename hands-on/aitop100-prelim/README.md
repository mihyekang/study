## 4. 사전 준비 체크리스트

### 4.1 카카오 계정·채널 정리

- [ ] 참가 신청 시 등록한 카카오 계정으로 로그인 가능 여부 확인 (다른 계정으로는 봇 문서 열람 불가)
- [ ] 보유 채널 수 확인: [카카오 비즈니스 채널 목록](https://business.kakao.com/profiles)
  - 계정당 채널 최대 10개, 10개면 대회용 채널 생성 불가
  - 미사용 채널 삭제로 최소 1개 여유 확보

### 4.2 카카오 디벨로퍼스 앱·카카오톡 봇 생성

- [ ] 참가 신청 계정으로 [카카오 디벨로퍼스](https://developers.kakao.com) 로그인
- [ ] [카카오톡 봇 튜토리얼](https://developers.kakao.com/docs/ko/bot/common) 열람 가능 여부 확인
- [ ] [앱 생성](https://developers.kakao.com/console/app) — 아래 값으로 설정

| 항목 | 설정값 |
|------|------|
| 앱 이름 | 자유 기입 |
| 회사명 | 앱 이름과 동일 |
| 카테고리 | 생산성/도구 |

- [ ] 카카오톡 봇 생성 → 카카오톡 채널 자동 생성·연결 확인
- [ ] 채널 설정에서 **검색 허용 안 함** 설정
- [ ] 운영정책(이용 제한 카테고리, 금지 내용·행동) 위반 소지 없는지 앱 정보 점검
- [ ] [REST API 문서](https://developers.kakao.com/docs/ko/bot/rest-api)에서 아래 3가지 확인 후 메모  
  (서버 `server/kakao_adapter.py` 수정에 필요)
  - 메시지 수신 방식 (웹훅으로 서버 호출 / 서버가 API 호출 / 로컬 게이트웨이)
  - 요청·응답 JSON 형식
  - 응답 제한시간 (초)
- [ ] 스마트폰 카카오톡에서 채널 추가 후 봇과 대화 가능한 상태 확인  
  — 10/28 메일 체크리스트의 "챗봇 사전 설정 완료" 기준

> 봇 제작은 당일 진행도 가능하나, 봇 문제로 미제출 시 지원·예외처리 없음. **사전 완료 강력 권장.**

### 4.3 에이전트 구동 서버

- [ ] 구동 방식 결정 — 심사 기간 수정 금지 규정으로 **고정 URL 클라우드 배포 사실상 필수**

| 방식 | 장점 | 단점 |
|------|------|------|
| 클라우드 배포 | PC 상태와 무관, 고정 URL, 33시간 무중단 유지 용이 | 배포 설정 필요, 비용 발생 가능 |
| 로컬 PC + 터널 | 설정 간단, 디버깅 편함 | 절전·재부팅 시 무응답, Quick Tunnel은 재시작마다 URL 변경 |

- [ ] 서버 골격(`server/`) 로컬 실행 확인 → 클라우드 배포 → HTTPS URL 확보
- [ ] 카카오톡 봇에 서버 연결 → 실제 메시지 1건 송신 → `server/logs/payloads.jsonl`로 실제 요청 형식 확인
- [ ] 확인한 형식대로 `server/kakao_adapter.py` 수정 → 카카오톡 실대화 재확인
- [ ] 심사 기간 무수정 운영 구성 확인
  - 최소 인스턴스 1 (콜드스타트·유휴 슬립 방지)
  - 저장소 push 시 자동 재배포되는 연동(CI 등)이 있으면 비활성화
- [ ] 외부 업타임 모니터에 `/health` 등록 (5분 간격, 다운 시 휴대폰 알림)
- [ ] LLM API 키 잔액·사용 한도 확인 (도구지원금 없음, 제출 후 약 33시간 심사 트래픽 고려)
- [ ] 실제 API 키로 `/webhook` 호출해 응답시간 측정 — 타임아웃(4.5초) 초과가 잦으면 `BOT_MODEL`을
  더 빠른 모델로 변경, 400 오류 시 `BOT_FALLBACKS=off` (상세: `server/README.md`)

### 4.4 환경 인증 사진

- [ ] [예선 대기실 입장하기] → 대회 입장 페이지 → **[대회 환경 인증]**에서 촬영 기준 사전 확인
- [ ] 얼굴·손 등 신체 일부가 프레임에 들어가지 않는 촬영 구도 연습 (거치대·책상 고정 촬영 고려)
- [ ] 1장만 제출·재제출 불가 → 촬영 후 기준 충족 여부 확인 뒤 제출

### 4.5 준비물·환경 점검

- [ ] 💻 개인 PC + **크롬 브라우저** 최신 버전 (충전기, OS 업데이트 사전 완료로 당일 강제 재부팅 방지)
- [ ] 🌐 개인 인터넷 회선 (공용 네트워크 금지, 가능하면 유선)
- [ ] 🤖 AI 도구: 로그인 상태, 구독·크레딧 잔여량 확인 (평소 쓰는 도구 자유 활용 가능)
- [ ] 📱 스마트폰: 완전 충전, QR 인식·사진 촬영 확인 (환경 인증 사진 제출용)
- [ ] 리허설: 임의 과제 1개로 "과제 분석 → 프롬프트 교체 → 배포 → 카카오톡 테스트" 1회 수행, 소요시간 측정
