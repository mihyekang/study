[목표]
LLM 모델을 사용한 화자 분리 음성 인식 프로그램 개발
[역할]
당신은 AI 개발자임
[입력]
- Audio 파일: `hands-on/audio/`의 첫번째 음성 파일
[처리]
- 예제 개발: Claude 에이젼트를 호출하여 병렬 개발  
  - {프로젝트}: llm-diarization
  - {AI벤더}: openai 중 하나 
  - AI모델 결정
    - 최신 모델 사용
    - OpenAI Whisper 사용
    - API Key는 `hands-on/.env` 파일 참조
  - 오디오 파일을 화자별로 구분하여 텍스트로 변환
  - 각 발화에 타임스탬프 포함 ([MM:SS] 형식)
  - AI 응답 후 각 화자별로 실제 이름을 입력받아 결과 파일에 반영
    - 샘플 발화를 보여주고 해당 화자의 실제 이름 입력
    - Enter 입력 시 기본 라벨 유지 (화자A, 화자B 등)
  - 파싱
    - AI 응답에서 [MM:SS] 화자X: 텍스트 형식만 추출
    - 설명/요약 등 부가 텍스트는 무시
  - 출력 파일: 
    - hands-on/05.stt/{프로젝트}/{AI벤더}/result.txt: 원본 변환 결과
    - hands-on/05.stt/{프로젝트}/{AI벤더}/result_chunks.csv: 구조화된 데이터 (pandas, 구분자 "|", 실제 이름 반영)
    - hands-on/05.stt/{프로젝트}/{AI벤더}/result.json: JSON 형식 결과 (실제 이름 반영)
- 테스트 및 버그 Fix
- README.md 작성
  - 기본 정보 : 목적, 기능 등
  - 소스 코드 설명 (주요 함수, 처리 흐름)
  - WhisperX와의 비교
  - 가상환경 구성 방법
  - 실행 방법
  - 출력 파일 형식 설명

[출력]
- hands-on/05.stt/{프로젝트}/{AI벤더}/(stt.py, README, requirements.txt)

[제약사항]
- MUST: 
  - 화자 분리 프롬프트는 한글로 작성
  - 화자A, 화자B 등으로 화자 구분
  - 감탄사, 추임새 등 자연스러운 발화 포함
