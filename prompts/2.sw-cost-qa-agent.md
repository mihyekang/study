(출력)
## 기능점수 방식 SW 개발비 산정 절차

**핵심 답변**  
기능점수(FP, Function Point) 방식은 소프트웨어의 기능 규모를 숫자로 측정해 개발비를 산정하는 방법입니다.

**관련 절차**  
1. 애플리케이션 경계 설정 — 대상 SW의 범위를 명확히 구분  
2. 데이터 기능 측정 — 내부논리파일(ILF)·외부연계파일(EIF) 식별 및 복잡도 산정  
3. 트랜잭션 기능 측정 — 외부입력(EI)·외부출력(EO)·외부조회(EQ) 식별 및 복잡도 산정  
4. 기능점수 합산 — 정통법 또는 간이법 적용  
5. 개발비 산정 — `기능점수 × 기능점수당 단가 × 보정계수`

**산정 근거식**  
`SW 개발비 = 기능점수(FP) × 기능점수당 단가 × 규모 보정계수 × 복잡도 보정계수`

- 기능점수당 단가: 최신 고시 기준 확인 필요 (매년 조정)  
- 규모 보정계수: 규모 구간별 상이 (가이드 [표 3-23] 참조)  
- 예) FP=500, 단가=A원, 보정계수=1.0이면 → 500 × A × 1.0 = **직접 산출 후 전문가 검산 권장**

**출처**: 가이드 Ⅲ-2.1 기능점수 방식, p.133~152

**주의사항**  
- 정통법(상세 복잡도 산정)과 간이법(평균 복잡도 적용) 중 사업 특성에 맞는 방법 선택 필요  
- 보정계수(규모·복잡도)는 사업 조건에 따라 달라짐

> 본 답변은 참고용이며, 최종 대가산정은 담당 전문가 확인 필요.
