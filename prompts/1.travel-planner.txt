[목표]
여행 계획을 짜주는 앱을 개발

[역할]
- 멀티턴과 슬라이딩윈도우 기법을 잘 아는 AI앱 개발자가 수행
- 여행 산업에 대한 업무 지식도 보유
- 클로니가 적절한 팀원에게 지시

[맥락]
- 내 상황: 선배가 나한테 멀티턴 대화를 연습하기 위한 앱 개발 숙제를 내줌
- 독자: 선배, 팀장님


[입력]
- 멀티턴 교재: C:\Users\User\workspace\aistudy\agentic-ai\textbook\02.멀티턴.md

[처리]
- 입력정보 이해

- 앱 개발
  - 사용자에게 여행할 도시를 요청함
  - 사용자에게 몇박 며칠인지 일정을 물어본다
  - LLM에 일정 생성 요청: Groq LPU를 사용하고 gpt-oss-120b를 사용
  - API Key는 hands-on/.env 를 참조
  - 멀티턴과 슬라이딩윈도우+요약 기법을 적용: Sliding window size는 3으로 함
  - 결과에 주변 지하철, 기차, 버스 정류장과 시간표를 연결함
  - 주변 맛집을 tripadvisor에서 높은 평점을 받은 걸로 추천해줘
  - 아침 9시부터 저녁 6시까지 일정 작서
  - 아침, 점심, 저녁 음식점 추천
  - 음식점과 관광지는 연결 링크도 꼭 추가
  - 의존성(라이브러리) 정의는 requirements.txt에 작성

- 테스트 및 버그 수정

- READ ME 작성
  - 앱 개요: 목적, 기능 등
  - 주요 소스 설명
  - 가상환경 설정 방법
  - 실행 방법
- 완료 보고
